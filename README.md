# CineScope website (Streamlit + Gradio)

Both sites show the full content of the CineScope final presentation (all 13 slides).

    pip install -r requirements.txt
    streamlit run streamlit_app.py     # Streamlit version
    python gradio_app.py               # Gradio version

Files: `content.py` (all slide content, shared), `streamlit_app.py`, `gradio_app.py`, `assets/` (diagrams from the slides).
